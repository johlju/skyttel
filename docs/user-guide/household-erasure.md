# Radera hushållets information permanent

[Till användarguidens innehåll](README.md)

En aktuell administratör kan radera utvald information permanent från
Skyttel. Öppna **Administrera tillgång** och gå till **Permanent radering**.
Vanliga medlemmar och externa assistenter kan inte göra detta.

Permanent radering kan inte ångras med Skyttels historik. Använd vanlig
borttagning eller markera något som avslutat när informationen ska finnas
kvar i historiken.

## Granska hela omfattningen

1. Markera objekten, sambanden eller typerna som ska raderas.
   Identifierarna skiljer poster med samma namn åt.
2. Välj **Granska raderingen**. Läs hela omfattningen innan du går vidare.
   En sammanslagen identitet kan omfatta båda ursprungliga objekten och
   kopierade bilder. En typ kan omfatta objekt eller samband som
   fortfarande använder den.
3. Kontrollera bildversioner, historiska ändringar, privata ändringar och
   personliga placeringar. Andras privata bilder och privata objekt som
   inte delas visas bara som antal. Granskningen ger dig inte tillgång
   till deras privata texter eller bilder.
4. Skriv **RADERA PERMANENT** och välj **Radera permanent** endast när
   omfattningen stämmer. Om något ändras måste du granska igen och skriva
   bekräftelsen på nytt.

Raderingen omfattar också berörd historik, bildversioner och privata
förslag. Oberoende information bevaras, även i ett utkast eller en sparad
ändring som också innehåller något som raderas. Ett objekt eller en
samband som tidigare hänvisade till informationen behöver därför inte
försvinna från dagens karta.

## Vid avbrott eller väntande städning

Ett förlorat svar betyder inte att raderingen misslyckades. Använd knappen
för att kontrollera raderingsstatus och läsa in aktuellt innehåll. Skyttel
behåller samma försök tills utfallet är känt. Du kan också öppna sidan
igen för att läsa den sparade statusen.

Under förberedelse och städning är berört innehåll tillfälligt låst.
Städningen kan påverka åtkomsten för hela installationen. Använd sidans
fortsättningsknapp för samma radering om den fortfarande väntar. Kontakta
driftansvarig om den inte kommer vidare. En annan aktuell administratör
kan fortsätta om den som startade raderingen förlorar sin tillgång.

Bara meddelandet **Den permanenta raderingen är slutförd.** bekräftar att
Skyttels städning är klar. Läs in kartan på nytt efteråt; gamla ändringar
och sparförsök kan inte läggas tillbaka genom att skickas igen.

## Kopior utanför raderingen

Redan nedladdade exporter ändras inte. Förvara eller ta bort dem enligt
hushållets beslut. En uttrycklig [import](household-import.md) av en äldre
export kan återställa information som raderas här.

Skyttel kan inte lova omedelbar fysisk radering från driftleverantörens
kopior eller lagringssystemets historik. Driftansvarig hanterar dessa
kopior separat. Raderingen tar bort Skyttels egna tillfälliga exporter
och importer innan den kan bli slutförd.
